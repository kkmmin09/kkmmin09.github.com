# PyQt5 + OpenCV 실시간 웹캠 & 캐니 엣지 검출 프로그램 코드 분석

웹캠 영상을 실시간으로 화면에 보여주고, 버튼을 누르면 캐니(Canny) 엣지 검출 결과를 옆 화면에 함께 보여주는 프로그램입니다. 별도 스레드에서 영상을 처리해 UI가 멈추지 않도록 구성되어 있습니다.

아래에서 코드를 부분별로 나눠 설명합니다.

---

```python
import cv2
import sys
from PyQt5 import QtCore
from PyQt5 import QtWidgets
from PyQt5 import QtGui
```
영상 처리를 위한 `cv2`(OpenCV)와, GUI 구성을 위한 PyQt5의 핵심 모듈들(`QtCore`, `QtWidgets`, `QtGui`)을 불러옵니다.

```python
class ShowVideo(QtCore.QObject):
    flag = 0
    camera = cv2.VideoCapture(0)
```
영상 캡처와 처리를 담당하는 클래스입니다. `flag`는 캐니 엣지 검출을 켜고 끄는 스위치이고, `cv2.VideoCapture(0)`으로 기본 웹캠을 연결합니다.

```python
    ret, image = camera.read()
    height, width = image.shape[:2]
```
클래스 정의 시점에 웹캠에서 프레임을 한 번 읽어와, 영상의 높이와 너비를 미리 구해둡니다.

```python
    VideoSignal1 = QtCore.pyqtSignal(QtGui.QImage)
    VideoSignal2 = QtCore.pyqtSignal(QtGui.QImage)
```
원본 영상과 캐니 엣지 처리된 영상을 각각 UI로 전달하기 위한 PyQt 시그널 두 개를 정의합니다.

```python
    def __init__(self, parent=None):
        super(ShowVideo, self).__init__(parent)
```
부모 클래스(`QObject`)의 생성자를 호출하는 기본 초기화 함수입니다.

```python
    @QtCore.pyqtSlot()
    def startVideo(self):
        global image
        run_video = True
        while run_video:
            ret, image = self.camera.read()
            color_swapped_image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
```
'Start' 버튼을 누르면 실행되는 함수. 무한 루프를 돌며 웹캠에서 프레임을 읽고, OpenCV의 BGR 색상 순서를 Qt에서 쓰는 RGB 순서로 변환합니다.

```python
            qt_image1 = QtGui.QImage(color_swapped_image.data,
                                    self.width,
                                    self.height,
                                    color_swapped_image.strides[0],
                                    QtGui.QImage.Format_RGB888)
            self.VideoSignal1.emit(qt_image1)
```
변환된 이미지 데이터를 Qt에서 표시 가능한 `QImage` 객체로 만들고, `VideoSignal1` 시그널을 통해 화면(원본 뷰어)으로 전달합니다.

```python
            if self.flag:
                img_gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
                img_canny = cv2.Canny(img_gray, 50, 100)
```
`flag`가 켜져 있으면(캐니 버튼을 누른 상태), 영상을 흑백으로 변환한 뒤 캐니 엣지 검출을 수행합니다.

```python
                qt_image2 = QtGui.QImage(img_canny.data,
                                         self.width,
                                         self.height,
                                         img_canny.strides[0],
                                         QtGui.QImage.Format_Grayscale8)
                self.VideoSignal2.emit(qt_image2)
```
엣지 검출 결과를 흑백(Grayscale) `QImage`로 만들어 `VideoSignal2` 시그널로 화면(엣지 뷰어)에 전달합니다.

```python
            loop = QtCore.QEventLoop()
            QtCore.QTimer.singleShot(25, loop.quit) #25 ms
            loop.exec_()
```
프레임 사이에 25ms의 딜레이를 줘서, 프로그램 전체가 멈추지 않으면서도 초당 약 40프레임 속도로 영상을 처리하도록 조절합니다.

```python
    @QtCore.pyqtSlot()
    def canny(self):
        self.flag = 1 - self.flag
```
'Canny' 버튼을 누를 때마다 `flag` 값을 0과 1 사이로 뒤집어, 엣지 검출 표시 여부를 토글합니다.

```python
class ImageViewer(QtWidgets.QWidget):
    def __init__(self, parent=None):
        super(ImageViewer, self).__init__(parent)
        self.image = QtGui.QImage()
        self.setAttribute(QtCore.Qt.WA_OpaquePaintEvent)
```
영상을 화면에 그려주는 위젯 클래스입니다. 빈 이미지로 초기화하고, 화면을 매번 완전히 새로 그리도록 설정해 깜빡임을 줄입니다.

```python
    def paintEvent(self, event):
        painter = QtGui.QPainter(self)
        painter.drawImage(0, 0, self.image)
        self.image = QtGui.QImage()
```
화면이 다시 그려질 때마다 저장된 이미지를 좌상단(0,0)부터 그리고, 그린 후에는 이미지를 비워둡니다.

```python
    def initUI(self):
        self.setWindowTitle('Test')
```
창 제목을 설정하는 함수입니다. (현재 코드에서는 별도로 호출되지 않음)

```python
    @QtCore.pyqtSlot(QtGui.QImage)
    def setImage(self, image):
        if image.isNull():
            print("Viewer Dropped frame!")
        self.image = image
        if image.size() != self.size():
            self.setFixedSize(image.size())
        self.update()
```
시그널로 새 이미지가 들어올 때마다 실행되는 슬롯 함수. 이미지가 비어있으면 경고를 출력하고, 위젯 크기를 이미지 크기에 맞춘 뒤 화면을 다시 그리도록 요청합니다.

```python
if __name__ == '__main__':
    app = QtWidgets.QApplication(sys.argv)
```
프로그램의 진입점. Qt 애플리케이션 객체를 생성합니다.

```python
    thread = QtCore.QThread()
    thread.start()
    vid = ShowVideo()
    vid.moveToThread(thread)
```
별도의 스레드를 하나 만들어 실행시키고, 영상 처리 객체(`vid`)를 그 스레드로 옮깁니다. 이렇게 하면 영상 처리 루프가 메인 UI 스레드를 막지 않습니다.

```python
    image_viewer1 = ImageViewer()
    image_viewer2 = ImageViewer()
    vid.VideoSignal1.connect(image_viewer1.setImage)
    vid.VideoSignal2.connect(image_viewer2.setImage)
```
원본 영상과 엣지 영상을 각각 표시할 뷰어 두 개를 만들고, 각 시그널을 해당 뷰어의 `setImage` 슬롯에 연결합니다.

```python
    push_button1 = QtWidgets.QPushButton('Start')
    push_button2 = QtWidgets.QPushButton('Canny')
    push_button1.clicked.connect(vid.startVideo)
    push_button2.clicked.connect(vid.canny)
```
'Start'와 'Canny' 버튼을 만들고, 각각 클릭 시 영상 시작 함수와 엣지 검출 토글 함수를 실행하도록 연결합니다.

```python
    vertical_layout = QtWidgets.QVBoxLayout()
    horizontal_layout = QtWidgets.QHBoxLayout()
    horizontal_layout.addWidget(image_viewer1)
    horizontal_layout.addWidget(image_viewer2)
    vertical_layout.addLayout(horizontal_layout)
    vertical_layout.addWidget(push_button1)
    vertical_layout.addWidget(push_button2)
```
두 뷰어를 가로로 나란히 배치하고, 그 아래에 버튼 두 개를 세로로 쌓아 전체 레이아웃을 구성합니다.

```python
    layout_widget = QtWidgets.QWidget()
    layout_widget.setLayout(vertical_layout)
    main_window = QtWidgets.QMainWindow()
    main_window.setCentralWidget(layout_widget)
    main_window.show()
    sys.exit(app.exec_())
```
구성한 레이아웃을 메인 윈도우의 중앙 위젯으로 설정하고, 창을 띄운 뒤 이벤트 루프를 실행합니다.
