# 파이썬 숫자 맞추기 게임 코드 분석

난이도를 선택하면 그 범위 안에서 랜덤 숫자가 정해지고, 사용자가 숫자를 입력하면서 정답을 맞춰가는 간단한 콘솔 게임입니다.

아래에서 코드를 부분별로 나눠 설명합니다.

---

```python
import random

print("난이도 선택")
print("1. 1~10")
print("2. 1~50")
print("3. 1~100")
```
랜덤 숫자 생성을 위한 `random` 모듈을 불러오고, 사용자에게 난이도 선택 메뉴를 보여줍니다.

```python
d = int(input("난이도: "))

if d == 1:
    end = 10
elif d == 2:
    end = 50
else:
    end = 100
```
사용자에게 난이도 번호를 입력받아, 그에 맞는 최대 범위(`end`)를 설정합니다. 1과 2가 아니면 모두 100으로 처리됩니다.

```python
answer = random.randint(1, end)

print("1부터 " + str(end) + " 사이 숫자 맞춰보세요")

cnt = 0
```
1부터 `end` 사이의 랜덤 정답을 생성하고, 안내 메시지를 출력합니다. 시도 횟수를 셀 변수 `cnt`를 0으로 초기화합니다.

```python
while True:
    try:
        x = int(input("숫자 입력: "))
        cnt = cnt + 1
```
무한 반복문 시작. 사용자로부터 숫자를 입력받고, 시도 횟수를 1 증가시킵니다. 숫자가 아닌 값을 입력하면 아래 `except`에서 처리됩니다.

```python
        if x < answer:
            print("작음")
        elif x > answer:
            print("큼")
```
입력한 숫자가 정답보다 작으면 "작음", 크면 "큼"을 출력해 힌트를 줍니다.

```python
        else:
            print("정답 " + str(cnt) + "번 만에 맞춤")
            break
```
입력한 숫자가 정답과 같으면 몇 번 만에 맞췄는지 출력하고 반복문을 종료합니다.

```python
    except:
        print("숫자를 쓰세요")
```
숫자가 아닌 값을 입력했을 때(예: 문자) 오류가 나는 것을 막고, 안내 메시지를 출력한 뒤 다시 반복합니다.
